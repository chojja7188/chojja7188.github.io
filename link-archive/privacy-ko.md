# 개인정보처리방침

시행일: 2026-11-13

Link Archive 개발자(이하 "운영자")는 Link Archive 앱(이하 "앱")을 이용하는 분의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 지킵니다.

## 1. 한눈에 보기
- **로그인하지 않으면** 저장한 링크는 내 기기 안에만 있고, 운영자는 아무 정보도 받지 않습니다.
- **구글로 로그인하면** 기기 간 동기화를 위해 계정 정보와 저장한 링크가 서버(Supabase)에 저장됩니다.
- 판매·광고 목적으로 개인정보를 남에게 넘기지 않습니다. 분석·추적 도구를 쓰지 않습니다.

## 2. 수집하는 정보와 목적

| 언제 | 항목 | 목적 |
|---|---|---|
| 구글 로그인 시 | 구글 계정 이메일, 이름·프로필 사진(구글이 제공하는 경우), 구글 계정 고유 ID | 회원 식별, 로그인 유지 |
| 로그인 후 동기화 시 | 사용자가 저장한 링크 URL, 설명, 썸네일(이모지 또는 이미지 주소), 카테고리 이름, 즐겨찾기 여부, 생성·수정·마지막 열람 시각 | 여러 기기 간 데이터 동기화·백업 |
| 서버 이용 시 자동 | 접속 IP 주소, 접속 시각 등 서버 로그 | 보안, 오류 대응 (서버 제공자가 처리) |

앱은 위치, 연락처, 사진, 카메라, 마이크 등 기기 권한을 요청하지 않습니다.

### 2-1. 기기 안에서만 처리하고 운영자에게 보내지 않는 정보

| 기능 | 처리 방법 |
|---|---|
| 클립보드 | **안드로이드**: 링크 추가 화면을 열 때 클립보드를 한 번 확인해, 링크가 복사돼 있을 때만 "붙여넣기" 버튼을 보여줍니다. **iOS**: 사용자가 애플의 붙여넣기 버튼을 누를 때만 읽습니다. 어느 쪽이든 내용은 기기 안에서만 확인하며, 저장하거나 전송하지 않습니다. |
| 다른 앱에서 공유한 링크 | 링크 추가 화면의 칸을 채우는 데만 씁니다. 사용자가 "저장"을 눌러야 일반 링크로 저장됩니다. |
| 제목·썸네일 자동 채우기 | 새 링크 주소를 입력하면 앱이 **그 웹사이트에 직접 접속**해 페이지 제목과 대표 이미지 주소를 읽어 빈 칸을 채웁니다. 운영자 서버나 다른 업체를 거치지 않습니다. 다만 해당 웹사이트는 브라우저로 방문할 때처럼 접속 정보(IP 주소 등)를 알 수 있습니다. |
| 백업 파일 | 사용자가 "백업 파일 만들기"를 누를 때만 기기에서 파일을 만들고, 저장할 곳(구글 드라이브, 메일 등)은 사용자가 직접 고릅니다. 앱이 파일을 따로 보내지 않습니다. 불러오기도 사용자가 고른 파일만 읽습니다. |
| 앱 안 언어 설정 | 고른 언어는 기기 안에만 저장합니다. |

## 3. 보유 기간과 파기
- 회원 정보와 동기화 데이터는 **회원 탈퇴(앱 설정 › 계정 삭제) 즉시** 서버에서 삭제됩니다.
- 삭제한 링크는 다른 기기에 삭제를 알리기 위해 내용을 비운 표시(ID·시각)만 탈퇴 전까지 남습니다.
- 로그아웃하면 그 기기 안의 데이터가 삭제됩니다(계정에는 남음). 앱을 지우면 기기 안의 데이터도 함께 지워집니다.
- 서버 로그는 서버 제공자의 정책에 따라 짧은 기간 보관 후 삭제됩니다.

## 4. 처리 위탁 및 국외 이전
운영자는 서비스를 위해 아래 업체에 처리를 맡기며, 이 과정에서 정보가 국외로 이전됩니다.

| 받는 자 | 국가 | 이전 항목 | 목적 | 보유 기간 |
|---|---|---|---|---|
| Supabase, Inc. | 일본 (AWS 도쿄 리전, ap-northeast-1) | 2절의 회원 정보·동기화 데이터·서버 로그 | 데이터 저장, 로그인 처리 | 회원 탈퇴 시까지 |
| Google LLC | 미국 | 구글 로그인 정보 | 구글 계정 로그인 | 구글 정책에 따름 |

이전 시점·방법: 로그인·동기화할 때 암호화된 네트워크(HTTPS)로 전송.
국외 이전을 원하지 않으면 로그인하지 않고 기기 안에서만 앱을 쓸 수 있습니다.

## 5. 제3자 제공
법령에 따른 요청이 있는 경우를 제외하고, 개인정보를 제3자에게 제공하지 않습니다.

## 6. 이용자의 권리
언제든 자신의 정보를 조회·수정·삭제할 수 있습니다.
- 조회·수정: 앱에서 직접
- 삭제: 앱 설정 › 계정 삭제 (서버 데이터 즉시 삭제)
- 그 밖의 요청: 아래 연락처로 이메일

## 7. 안전성 확보 조치
- 모든 통신은 HTTPS로 암호화합니다.
- 서버의 행 수준 보안(RLS)으로 본인 데이터만 읽고 쓸 수 있게 막습니다.
- 앱은 비밀번호를 저장하지 않습니다(구글 로그인만 사용).
- 안드로이드 자동 백업에서 앱 데이터를 제외해, 기기 안의 링크·로그인 정보가 구글 클라우드 백업으로 복사되지 않게 합니다.
